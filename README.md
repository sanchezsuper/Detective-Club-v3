# Detective Club v3

Гібридний детективний квест для друзів: онлайн-частина (сайт клубу) + частина на свіжому повітрі (місце злочину, тріангуляція, закопаний контейнер).

- **[docs/QUEST_PLAN.md](docs/QUEST_PLAN.md)** — опрацьовані ідеї, рекомендації, план робіт та алгоритм проходження (з візуальними картами).

Наступний етап — веб-частина: лендінг-запрошення, реєстрація, лобі, таймер, завдання, брифінг.
