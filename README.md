# Detective Club v3

Гібридний детективний квест для друзів: онлайн-частина (сайт клубу) + частина на свіжому повітрі (місце злочину, тріангуляція, закопаний контейнер).

- **[docs/QUEST_PLAN.md](docs/QUEST_PLAN.md)** — опрацьовані ідеї, покроковий сценарій, план робіт та алгоритм проходження (з візуальними картами).

## Запуск прототипу

Статичний сайт, бекенд не потрібен:

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

> Розсекречення досьє використовує WebCrypto — сайт має відкриватися через `http://localhost` або `https` (не через `file://`).

## Режим ведучого

Відкрийте `http://localhost:8000/?host=1` — з'явиться панель ведучого: кнопка **СТАРТ** (запускає відлік у кабінеті), **Скинути гру** та швидкі переходи на всі екрани.

## Шпаргалка ведучого (тестові ключі)

| Крок | Ключ |
|---|---|
| Завдання-допуск | «людина» |
| Термінал: логін (завдання Л, перші літери імен) | `СОКІЛ` / `SOKIL` |
| Термінал: пароль (завдання П, римські I IX IV VII) | `1947` |
| PIN розсекречення досьє (годинник 21 + дзвінок 47 + піджак 53) | `214753` |
| Фінальний код (номер посвідчення) | `X-2604` |

Розсекречена частина досьє зашифрована AES-GCM ключем із PIN — без правильного PIN тексту фізично немає на сторінці (справжнє «засекречено», а не приховане стилями).

## Екрани

`#/` лендінг-запрошення · `#/register` реєстрація · `#/task` завдання-допуск · `#/cabinet` кабінет (лобі, таймер, секретна кнопка 🔒 після старту) · `#/terminal` термінал Служби Х (кнопка «i» — підказки) · `#/dossier` досьє з розсекреченням · `#/phone` телефон жертви (ціль QR на локації) · `#/denied` «ДОСТУП ЗАБОРОНЕНО» (QR-обманка) · `#/solved` фінальний код · `#/news` новина-епілог (твіст 2)

## Наступні етапи

- Мультиплеєр: спільне лобі та синхронний таймер (потрібен простий бекенд або Firebase/Supabase).
- Заміна тестових завдань на бойові; підстановка реальної адреси локації та точок тріангуляції (позначки `[ЗАМІНИТИ]` у зашифрованому блоці — перегенерувати шифр після редагування).
