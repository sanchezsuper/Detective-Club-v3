# Detective Club v3

Гібридний детективний квест для друзів: онлайн-частина (сайт клубу) + частина на свіжому повітрі (місце злочину, тріангуляція, закопаний контейнер).

- **[docs/QUEST_PLAN.md](docs/QUEST_PLAN.md)** — опрацьовані ідеї, покроковий сценарій, план робіт та алгоритм проходження (з візуальними картами).

## Запуск прототипу

Статичний сайт, бекенд не потрібен. **Найпростіше (Windows): подвійний клік по `index.html`** — все працює прямо з файлу, включно з розсекреченням (перевірено в Chrome/Edge).

Через локальний сервер (за бажанням):

```bash
# Windows (з пробілом після python; або py, якщо python не знаходиться)
python -m http.server 8000
py -m http.server 8000

# Linux / macOS
python3 -m http.server 8000
```

Запускати **з папки проєкту** (`cd` у папку з `index.html`; у терміналі має з'явитися `Serving HTTP on ...`).

> Якщо `http://localhost:8000` довго вантажиться і нічого не показує — відкрийте **`http://127.0.0.1:8000`**. На Windows браузер інколи резолвить `localhost` в IPv6 (`::1`), а сервер Python слухає лише IPv4 — сторінка «висить». `127.0.0.1` обходить це.

## Режим ведучого

Додайте `?host=<ключ>` до адреси (ключ за замовчуванням: `shef003`):
- з файлу: `file:///...:/Detective-Club-v3/index.html?host=shef003`
- із сервера: `http://127.0.0.1:8000/?host=shef003`

З'явиться панель ведучого: кнопка **СТАРТ** (запускає відлік у кабінеті), **Скинути гру**, перемикач **«Набір: ВІДКРИТО/ЗАКРИТО»** (поки закрито — гості з візиток бачать заглушку «Справа № 003 готується»; відкриття показує лендінг усім наживо) та швидкі переходи на всі екрани. Ключ зберігається в коді лише як SHA-256-хеш, тому гравці його не підглянуть.

## Розміщення в інтернеті (щоб грали всі)

Найпростіше — **GitHub Pages** (безкоштовно, https, нічого не треба встановлювати):

1. Злити гілку в основну (main).
2. На GitHub: **Settings → Pages → Build and deployment → Deploy from a branch** → гілка `main`, папка `/ (root)` → Save.
3. За хвилину сайт живе на `https://<ваш-нік>.github.io/Detective-Club-v3/` — це посилання й кидаєте друзям.

Безпека при публічному коді: всі відповіді (допуск, логін, пароль, фінальний код) зберігаються **тільки як SHA-256-хеші**, а секретна частина досьє **зашифрована AES-GCM** — навіть відкривши вихідний код, підглянути нічого не можна. Альтернативи GitHub Pages: Netlify / Vercel / Cloudflare Pages (перетягнути папку — отримати посилання).

## Спільне лобі (Firebase, безкоштовно)

Без налаштування сайт працює **автономно**: профіль у `localStorage`, лобі показує лише вас, СТАРТ діє на одному пристрої. Щоб усі гравці бачили одне одного, СТАРТ був синхронний, а ведучий міг видаляти дублікати — вмикається **Firebase Realtime Database** (тариф Spark: безкоштовно, без картки; ліміт 100 одночасних з'єднань — для компанії з 10 людей запас десятикратний).

### Як увімкнути (один раз, ~5 хвилин)

1. [console.firebase.google.com](https://console.firebase.google.com) → **Create a project** (Google Analytics — вимкнути).
2. **Build → Realtime Database → Create Database** → локація `Belgium (europe-west1)` → **Start in locked mode**.
3. Вкладка **Rules** → замінити вміст на це → **Publish**:

```json
{
  "rules": {
    "rooms": {
      "case003": {
        ".read": true,
        ".write": true,
        "players": { "$id": { ".validate": "newData.hasChildren(['name'])" } }
      }
    }
  }
}
```

4. **Project settings (шестерня) → Your apps → Web `</>`** → зареєструвати app (Firebase Hosting не потрібен) → скопіювати `firebaseConfig`.
5. Вставити цей об'єкт у **`js/firebase-config.js`** замість `null` (приклад — у коментарі там же; важливо, щоб було поле `databaseURL`).

Конфіг публічний за дизайном Firebase — у відкритому репозиторії йому нічого не загрожує: доступ обмежують правила, а всі відповіді квесту й так зберігаються хешами/шифром.

### Що дає

- **Лобі:** у кабінеті всі детективи зі статусами («проходить допуск» / «допуск отримано» / «не на зв'язку»), оновлюється наживо.
- **Синхронний СТАРТ:** кнопка ведучого пише серверний час у базу — хронометр стартує у всіх одночасно (з поправкою на годинники пристроїв).
- **Ведучий керує складом:** у лобі біля кожного гравця кнопка **✕** — видаляє дублікат/повторний вхід; у видаленого гравця профіль скидається і він повертається на реєстрацію. «Скинути гру» тепер чистить кімнату для всіх.
- **Без дублів при поверненні:** гравець отримує `playerId` у `localStorage` — повторний вхід з того самого браузера оновлює його ж запис, а не створює новий.

## Шпаргалка ведучого (тестові ключі)

| Крок | Ключ |
|---|---|
| Завдання-допуск | «секрет» або «таємниця» |
| Термінал: логін (завдання Л, перші літери імен) | `СОКІЛ` / `SOKIL` |
| Термінал: пароль (завдання П: Єлизавета **II** · Іван **IV** Грозний · Генріх **VIII** · Фрідріх **II** Великий) | `2482` |
| PIN розсекречення досьє (№1 годинник 2147 + №2 піджак 53 + №3 зброя 12; порядок = номери речдоків) | `21475312` |
| Код телефона жертви (19.08 — д.н. з розсекреченого досьє) | `1908` |
| Фінальний код (номер посвідчення) | `X-2604` |
| Ключ режиму ведучого (`?host=...`) | `shef003` |

Розсекречена частина досьє зашифрована AES-GCM ключем із PIN — без правильного PIN тексту фізично немає на сторінці (справжнє «засекречено», а не приховане стилями).

## Екрани

`#/` лендінг-запрошення · `#/register` реєстрація · `#/task` завдання-допуск · `#/cabinet` кабінет (лобі, таймер, секретна кнопка 🔒 після старту) · `#/terminal` термінал Служби Х (кнопка «i» — підказки) · `#/dossier` досьє з розсекреченням · `#/phone` телефон жертви (ціль QR на локації) · `#/denied` «ДОСТУП ЗАБОРОНЕНО» (QR-пастка: зареєстрований детектив, що відсканував, блокується на 3 хвилини — всі екрани ведуть на denied з відліком; тривалість — константа `BLOCK_MS` у js/app.js; ведучого пастка не чіпає) · `#/solved` фінальний код; за кілька секунд після «СПРАВУ РОЗКРИТО» знизу виповзає бігучий рядок «Новина дня» — твіст 2

## Інструменти ведучого (папка props/)

- `frame.html` — «Рамка речдоків»: перетягнув фото → полароїд із биркою і підписом.
- `map.html` — «Мапа справи»: скріншот OSM → калібрування двома кліками → друкована мапа з точною шкалою внизу і відривною лінійкою збоку (масштаб вірний навіть якщо принтер стисне сторінку — лінійка друкується разом з мапою).
- `letter.html` — лист Олені для друку; `id-card-source.html` — посвідчення; `props-source.html` — векторні полароїди.
- `report-card.html` — «Рапорт 003-Р» у контейнер: QR веде на фінальний екран, де вводять номер знайденого посвідчення (перше сканування назавжди відкриває вкладку ДОПОВІДЬ у нижній навігації).
- `blocked-qr.html` — наліпки-пастки 5×5 см («Блокування, не переходь!») до речдоків на місці злочину: QR веде на «ДОСТУП ЗАБОРОНЕНО» і блокує детектива на 3 хвилини.
- `phone-qr.html` — наліпки «СХОВИЩЕ-7» на речдок № 4 (розбитий телефон): QR веде на хмарне дзеркало телефону жертви.
- `thanks.html` — «ПОДЯКА» спецгрупі: фінальний аркуш у контейнер (найнижчим шаром), з місцем для імен і підпису.
- `invite-cards.html` — візитки-запрошення 90×50 мм (10 шт/А4) з QR на сайт: роздаються заздалегідь; до відкриття набору гості бачать «Справа № 003 готується».
- `print/` — фотокомплект для друкарні: 6 кадрів 10×15 (речдоки, фото з газетою, посвідчення з лінією згину) + зведений `print-kit-photos.pdf`.

## Наступні етапи

- Заміна тестових завдань на бойові: нові відповіді — це нові SHA-256-хеші в `js/app.js` (`HASHES`), команда генерації — у коментарі поруч.
- Підстановка реальної адреси локації та точок тріангуляції (позначки `[ЗАМІНИТИ]` у зашифрованому блоці — перегенерувати шифр після редагування).
